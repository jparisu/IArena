# Phase 2: Architect

Define the technical structure and the test approach before implementation.

## Required Work

- Create the implementation skeleton or module plan.
- Define the test strategy.
- Specify sunny-path, corner-case, and failure-case coverage.
- Prefer arranging tests to fail before implementation when applicable.
- Identify documentation and validation work that must follow implementation.

## Phase Output

- implementation structure or skeleton plan
- test strategy
- explicit test cases for happy path, corner cases, and failure cases
- expected documentation and validation follow-up

## Human Gate

`Please review the architecture and test plan. Should I continue to implementation?`
