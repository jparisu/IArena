# Phase 2: Architect

Create the technical structure, implementation skeleton, and failing tests before implementation.

## Required Work

- Create the target file structure and implementation skeleton that the implementation phase will fill in.
- Implement the planned test files and cases before the feature implementation is added.
- Define the test strategy alongside the skeleton so coverage is explicit.
- Specify sunny-path, corner-case, and failure-case coverage.
- Run the relevant tests and confirm they fail for the expected not-yet-implemented behavior before moving on.
- Identify documentation and validation work that must follow implementation.

## Phase Output

- created file structure and implementation skeleton summary
- failing test implementation summary
- test strategy
- explicit test cases for happy path, corner cases, and failure cases
- failing test evidence summary
- expected documentation and validation follow-up

## Human Gate

`Please review the architecture, scaffolding, and failing tests. Should I continue to implementation?`
