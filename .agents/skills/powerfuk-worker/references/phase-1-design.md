# Phase 1: Design

Design the change and update the design artifacts before writing code.

## Required Work

- Identify the current state and the intended new state.
- Define the expected behavior and scope.
- Propose the public API or interface changes when relevant.
- Identify efficiency, reuse, simplification, or maintainability opportunities.
- Call out assumptions, dependencies, risks, and open questions.
- Update the relevant `design/` files so they match the approved design direction.
- Create or update class diagrams when structure or responsibilities need visual clarification.
- Create or update sequence diagrams when workflows or interactions need visual clarification.

## Phase Output

- current state summary
- target behavior summary
- relevant API or interface proposal
- updated design artifact summary
- class and sequence diagram summary when created or updated
- notable risks, assumptions, and opportunities
