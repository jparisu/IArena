**IArena** is a Python game framework library to build turn-based games, define AI players, and run matches or tournaments for experimentation and teaching.

The repository currently provides a clean skeleton to implement the framework from scratch with modern packaging, tests, linting, and docs tooling.

📘 **Documentation:** [https://iarena.readthedocs.io](https://iarena.readthedocs.io)


## Installation

Install from the GitHub repository:

```bash
pip install git+https://github.com/jparisu/iarena.git
```

Install for local development:

```bash
pip install -e ".[dev]"
```
