Let's start implementing module `playing`,
This module will implement generic players that are able to play any game.

Implement `RandomPlayer` that allow whether a random generator, a seed, or none.
If none is used, generate a random generator without seed, so it will be different every time.

Also implement a `TerminalPlayer` such that the user can play the game in the terminal. This player will ask for the possible movements, and the user will input the movement they want to do. This player will be useful for testing and debugging purposes, as well as for playing the game in a non-graphical way.
